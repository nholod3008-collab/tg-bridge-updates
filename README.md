# TG Bridge — Android обновления

Это официальный **публичный канал релизов TG Bridge**.

- **Исходный код приложения остаётся приватным**: этот репозиторий предназначен исключительно для готовых подписанных APK и описаний выпусков.
- Новые версии будут публиковаться на странице **Releases**.
- После запуска стабильной версии TG Bridge сможет проверять файл `latest.json` по HTTPS, сообщать о выпуске и предлагать кнопку **«Скачать и установить»**.
- Android всегда запрашивает подтверждение установки; приложение проверяет контрольную сумму SHA-256 и совместимость цифровой подписи APK.

## Текущее состояние (21 ноября 2026)

**Канал создан, но первый стабильный выпуск пока не опубликован.**
Рабочая версия TG Bridge 1450 ещё подписана отладочным ключом.
Для клиентских обновлений нужен **постоянный релизный сертификат**. Первый переход может требовать одноразовой переустановки, следующие выпуски будут обновляться поверх первого релизного APK.

Файл `latest.json` появится **только после** публикации реального, проверенного и подписанного APK. Не публикуем несуществующую версию или фиктивную ссылку.

Платежи и подписки в этот канал не входят.
